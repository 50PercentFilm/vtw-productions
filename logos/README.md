# VTW logo files

Wordmark is outlined (no font needed). Colours: Ink #0A0A0A, Bone #ECE8DF, Curtain red #B3121F, Cream #F4EDE0.

- `svg/vtw-lockup-*.svg` and `png/vtw-lockup-*.png`: mark + VTW, in ink, bone and curtain red (transparent background)
- `svg/vtw-stacked-*.svg` and `png/vtw-stacked-*.png`: mark with VTW underneath
- `svg/vtw-mark-*.svg` and `png/vtw-mark-*.png`: the two-ring mark alone
- `svg/vtw-stacked-*.svg` and `png/vtw-stacked-*.png`: mark above VTW (transparent background)
- `svg/vtw-avatar-*.svg` and `png/vtw-avatar-*-1000.png`: square profile pictures with the mark and VTW underneath (curtain red and ink)
- `vtw-avatar-mark-*`: the same profile pictures with the mark only
- `svg/vtw-og-image.svg`: social share image (the PNG is `og-image.png` in the site root)

Site root also holds `favicon.svg`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`.
Use the ink version on light backgrounds, bone on dark, curtain red on bone. Keep clear space equal to the height of the mark.

The letters in VTW touch, as on the website. Do not add spacing between them.
